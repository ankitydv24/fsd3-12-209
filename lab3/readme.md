 one of the most important module in node.js,orifinally designed for building scalable network application and web servers.

 1. create web servers
 2. handle client request
 3. build REST APIs
 4. non-blocking I/O
 5. Foundation of express.js

 HTTP - hyper text transfer protocol
 HTML - hyper text markup language 
 
 NPM - node package manager


 ## http status codes -> res.writehead( ), res.statuscode
 - 200 -> ok
 - 201 -> created
 - 400 -> bad request
 - 401 -> unauthorized
 - 403 -> forbidden
 - 404 -> not found
 - 500 -> internal server error

 ## Type of informatoin -> res.writehead( ), res.sethead( )
1. text/html -> for html file/contents
2. text/json , application/json -> for json data
3. text/css -> for css file/contents
4. apllication -> for file
5. text/plain -> for plain text file
